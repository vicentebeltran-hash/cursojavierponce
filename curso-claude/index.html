Módulo 01 · Fundamentos

¿Qué es Claude?

La base que necesitas antes de empezar. Entender qué es Claude te ayudará a sacarle mucho más partido en el día a día.

Claude es un asistente de IA de Anthropic

Claude es un modelo de lenguaje grande (LLM) creado por Anthropic. A diferencia de un buscador, Claude entiende el contexto, razona, redacta, analiza y puede ejecutar tareas complejas de forma autónoma.

💬

No es un buscador

Razona a partir de su entrenamiento y del contexto que tú le das, no indexa la web en tiempo real.

🧠

Entiende el contexto

Recuerda todo lo que ha pasado en la conversación actual y puede trabajar con documentos largos.

🤖

Puede actuar

Con herramientas (MCP, Claude Code) puede leer archivos, navegar la web, enviar emails y más.

La familia de modelos

ModeloPara qué sirveVelocidad
HaikuTareas rápidas, clasificación, chatbots de volumenMuy rápido
SonnetEquilibrio ideal: redacción, análisis, código, uso diario profesionalRápido
OpusRazonamiento complejo, estrategia, decisiones de alta importanciaPotente
💡 Para RK by realmark: Sonnet cubre el 95% del uso diario. Usa Opus para análisis de inversión o estrategia.

Concepto clave: la ventana de contexto

Claude trabaja dentro de una ventana de contexto — una memoria de trabajo de la sesión. Todo lo que le dices, archivos adjuntos, respuestas... va llenando esa ventana.

⚠️ Importante: Claude no recuerda sesiones anteriores por defecto. Cada conversación nueva empieza desde cero, salvo que uses CLAUDE.md para instrucciones persistentes.

Módulo 03 · Fundamentos

Modos de edición en Claude Code

Uno de los conceptos más importantes del curso: cómo controlar cuánta autonomía tiene Claude cuando trabaja con tus archivos.

Cambiar entre modos: Shift + Tab

En Claude Code, puedes ciclar entre cuatro modos pulsando Shift + Tab. Cada modo define cuánto puede hacer Claude sin pedirte permiso.

Manual
Pregunta antes de cada edición de archivo y cada comando. El más seguro.
✓ Para aprender o en proyectos críticos
Accept edits
Edita archivos y comandos básicos sin preguntar. Pide permiso para acciones avanzadas.
✓ Uso diario. ⚠️ Ojo con los botones de la barra inferior
Plan
Solo analiza y propone un plan. No toca nada.
✓ Antes de cambios grandes: entender primero
Auto
Actúa con comprobaciones de seguridad en segundo plano. Máxima autonomía.
✓ Tareas largas en las que confías plenamente
⚠️ Aviso del curso (Javier Ponce): En el modo Accept edits y en /loop, los botones de aceptar cambios aparecen en la parte inferior de la caja de texto. Es fácil aceptar sin darse cuenta. Revisa siempre antes de hacer clic.

Módulo 04 · Fundamentos

Comandos clave

Los slash commands y herramientas externas más importantes del curso.

Slash commands esenciales

/loop

Modo de iteración continua. Claude repite una tarea en ciclos. ⚠️ Ojo con los botones de aceptación en la barra inferior del text box.

/goal

Define un objetivo persistente que Claude persigue durante toda la sesión. Muy útil para tareas largas con un fin claro.

/compact

Comprime el historial para liberar espacio en la ventana de contexto. Se puede usar con foco:

/compact focus on los cambios de API
/context

Muestra qué está ocupando espacio en el contexto ahora mismo. Úsalo antes de /compact para saber si hace falta.

/model

Cambia entre Haiku, Sonnet y Opus durante la sesión. Sin cerrar ni reabrir.

/init

Crea un CLAUDE.md para el proyecto con instrucciones persistentes. Esencial para trabajo en equipo.

Cómo funciona /compact en detalle

La ventana de contexto se llena con el historial. Cuando se acerca al límite, Claude compacta automáticamente — pero tú puedes hacerlo manualmente con más control.

✅ Se preserva
  • Tus peticiones importantes
  • Fragmentos de código clave
  • El estado actual del trabajo
⚠️ Puede perderse
  • Instrucciones detalladas del principio
  • Contexto de decisiones anteriores
💡 Tip: Añade una sección Compact Instructions en tu CLAUDE.md para decirle a Claude qué preservar siempre al compactar.

Módulo 05 · Técnico

API vs MCP: la diferencia clave

Entender esta diferencia te ayudará a saber qué herramienta usar en cada situación.

API — Application Programming Interface

Un contrato de comunicación entre dos sistemas. Defines endpoints, métodos, parámetros y formatos de respuesta. Tú la llamas explícitamente desde código.

🍕 Analogía: Llamar por teléfono a un restaurante. Tú marcas el número, pides lo que quieres siguiendo su menú, y ellos te dan exactamente eso. Tú tienes que saber el número y el menú.
  • ¿Quién la llama? Tu código, explícitamente
  • ¿Quién sabe cómo usarla? El desarrollador
  • Estándar: Cada servicio tiene el suyo
  • Uso típico: Integración entre sistemas
MCP — Model Context Protocol

Un protocolo estándar de Anthropic que permite a Claude conectarse a herramientas y servicios externos y usarlas por sí solo, sin que le indiques cómo.

🏙️ Analogía: Un asistente que ya conoce todos los restaurantes de la ciudad y puede ir a buscar lo que necesitas sin que le expliques nada. Tú dices "tengo hambre de pizza" y él sabe a dónde ir.
  • ¿Quién la llama? Claude, de forma autónoma
  • ¿Quién sabe cómo usarla? Claude la descubre sola
  • Estándar: Protocolo universal
  • Uso típico: Darle "superpoderes" a Claude
🔗 Relación entre ambas: Un servidor MCP por debajo usa APIs. El MCP de Vercel que tienes en esta sesión llama internamente a la API REST de Vercel — pero Claude no necesita saber nada de eso. El MCP es la capa que traduce las capacidades de una API al lenguaje que Claude entiende.
Módulo 06 · Técnico

N8N + Automatización con Claude

N8N es la plataforma que convierte a Claude en el motor de tus automatizaciones de negocio, sin necesidad de código.

¿Qué es N8N?

N8N es una plataforma de automatización de flujos de trabajo visual — tipo Zapier o Make, pero más potente y con posibilidad de alojarlo tú mismo. Conectas aplicaciones entre sí con un editor visual de nodos, sin apenas código.

Ahora tiene integración nativa con Claude, lo que significa que puedes meter IA en medio de cualquier automatización.

Módulo 07 · Equipo en la Nube

Entornos en la nube

La base del trabajo en equipo con Claude. Entender qué es un entorno en la nube es el primer paso para que RK by realmark trabaje de forma colaborativa.

Sesión local vs sesión en la nube

💻 Sesión Local
  • Se ejecuta en tu ordenador
  • Solo tú puedes verla
  • Se para cuando cierras el portátil
  • Accede a tus archivos locales
  • Sin configuración de entrada
☁️ Sesión en la Nube
  • Se ejecuta en servidores de Anthropic
  • Compartible con el equipo
  • Sigue corriendo aunque cierres el PC
  • Accede a repositorios GitHub
  • Configurable por el administrador

Cómo funciona una sesión en la nube

1

Lanzas la sesión

Desde claude.ai, app de escritorio, móvil o terminal (claude --cloud). Aparece un selector de entorno.

2

Se crea una máquina virtual

Anthropic lanza un servidor Ubuntu 24.04 limpio con herramientas preinstaladas. No es tu ordenador.

3

Claude trabaja en ese servidor

Accede a repositorios de GitHub, ejecuta código, instala paquetes — todo aislado.

4

Retomable desde cualquier dispositivo

Empieza en el portátil, continúa desde el móvil sin perder nada.

Niveles de acceso de red

NivelQué permitePara qué
NoneSin acceso a internetTareas internas aisladas
Trusted ⭐Registros de paquetes, GitHub, SDKs comunesPunto de partida recomendado

🛡️ Sobre secretos: Los entornos en la nube aún no tienen almacén de secretos. No pongas contraseñas ni API keys en las variables de entorno — cualquier miembro con acceso al entorno podría leerlas.
Módulo 08 · Equipo en la Nube · ⭐ Clave para RK

Entornos compartidos y autoalojados

La funcionalidad más importante para que todo el equipo de RK by realmark trabaje de forma unificada.

Entornos compartidos de organización

Los entornos compartidos son entornos en la nube creados por el administrador que aparecen automáticamente en el selector de todos los miembros del equipo. En lugar de que cada persona configure el suyo, el admin crea uno estándar que todos comparten.

✅ Disponible en planes Team y Enterprise. RK by realmark necesita uno de estos planes para crear entornos compartidos.
🔄

Configuración única

El admin configura el entorno una vez. El equipo entero lo tiene disponible sin hacer nada.

📏

Estándares unificados

Todos los agentes trabajan con las mismas herramientas y accesos. Sin dispersión.

👀

Control de acceso

Solo Owners y Admins crean o editan entornos. Los miembros solo los usan.

Cómo crear el entorno compartido para RK

1

Admin Settings → Cloud environments

En claude.ai, solo Owners y Admins ven esta sección.

2

Crear el entorno

Clic en "Add cloud environment". Nombre descriptivo: "RK Producción" o "Equipo Comercial".

3

Configurar acceso de red

Elegir Trusted para empezar, o Custom si necesitáis acceder a APIs propias.

4

Script de inicio (opcional)

Script Bash que se ejecuta antes de que Claude empiece. Instala herramientas propias de la agencia.

5

Establecer como entorno por defecto

En Admin Settings → Claude Code. Todo el equipo lo usará automáticamente.

💬 Claude Tag en Slack: Si usáis Claude Tag en Slack, las sesiones de Slack solo pueden usar entornos compartidos, no personales. Por eso es crucial tenerlos configurados.

Entornos autoalojados (Self-hosted)

🔍 ¿Es esto para RK by realmark? Probablemente no de inicio. Los entornos autoalojados son para empresas con requisitos muy específicos de seguridad o compliance. Para la mayoría de agencias, los entornos de Anthropic son suficientes y mucho más sencillos.
☁️ Alojado por Anthropic
  • ✅ Sin infraestructura que mantener
  • ✅ Listo para usar inmediatamente
  • ✅ Actualizaciones automáticas
  • ⚠️ El código se procesa en servidores de Anthropic
🏢 Autoalojado
  • ✅ El código nunca sale de tu red
  • ✅ Acceso a servicios internos privados
  • ⚠️ Requiere infraestructura propia
  • ⚠️ Requiere equipo técnico para mantenerlo

Disponible en beta pública para planes Team y Enterprise. Un Owner o Admin activa "Allow self-hosted environments" en Admin Settings → Cloud environments.
